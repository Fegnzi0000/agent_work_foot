# Windows 本机运行脚本快照

这些脚本的原始运行位置是与 `frontend`、`backend` 同级的 `本地环境`。先复制到该目录再执行，不能直接在此快照目录执行。D 盘安装位置为当前开发机约定，同学可审阅后调整。

此目录不包含任何真实密钥。DPAPI 加密文件属于各自 Windows 账户，不能复制给同学作为配置。完整变更、启动、测试和回滚说明见上级目录的团队交接文档。

管理员创建用 `manage-local-accounts.ps1 -Operation create-admin`，不要再运行已停用的邮箱演示初始化。清理工具需要先核验归属、预览、备份和精确确认；它不是供用户直接访问的接口。
